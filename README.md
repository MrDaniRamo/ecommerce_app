# ecommerce_app
Quick example of an e-commerce app built and implemented with claude code

## Storefront demo

[`storefront/`](storefront/) holds **Los Dados del Norte**, a demo shop for D&D dice and accessories from Monterrey, Nuevo León. It's built with React, in Spanish with an English switch, with prices in Mexican pesos and a page for every product. Open `storefront/index.html` in a browser to try it. [`storefront/README.md`](storefront/README.md) explains how the page is built and how to change it.

Live site: https://mrdaniramo.github.io/ecommerce_app/ (published from `storefront/` by the GitHub Pages workflow in `.github/workflows/pages.yml`).

The logo artwork is in [`brand/`](brand/); [`tools/prep_logos.py`](tools/prep_logos.py) turns it into the web images the shop uses.
