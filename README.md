# ecommerce_app
Quick example of an e-commerce app built and implemented with claude code

## Storefront demo

[`storefront/`](storefront/) holds **Twenty Sides**, a demo shop for D&D dice and accessories, built with React and with a page for every product. Open `storefront/index.html` in a browser to try it. [`storefront/README.md`](storefront/README.md) explains how the page is built and how to change it.
